# 《像素分形水族箱》Pixel Fractal Aquarium

一个将数学之美与数字生命融合的交互式 3D 水族箱——曼德博罗集作为海底"基因图谱"动态编码珊瑚礁的形态，鱼群的实时游弋轨迹又反过来影响珊瑚的生长与色彩，形成"基因→骨骼→生命→反馈基因"的闭环生态；整个体验用像素风格的复古滤镜包裹。

**技术栈**：TypeScript + Three.js（WebGL2）+ GLSL Shader · **构建**：Vite

## 快速开始

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可进入 M0 技术预览。生产构建使用 `npm run build`，单元测试使用 `npm test`。

当前 M0 预览包含：

- 曼德博罗集 Fragment Shader，可调 `c` 坐标、缩放和迭代深度；
- 低分辨率 RenderTarget + Nearest 放大 + Bayer 有序抖动；
- 调色板、扫描线、像素密度、暂停和重置控制；
- 基于空间哈希的 Boids（分离 / 对齐 / 聚合）鱼群模拟；
- 64×64 生态影响场，记录鱼群轨迹的养分、扰动和活跃度，并按时间衰减；
- 32×20 像素鱼网格，包含礁鲷、神仙鱼、小丑鱼和蝠鲼幼体四种轮廓，网格本体严格按速度向量旋转，带双帧摆尾、漫游水流、转向缓动、转向侧倾、深度分层和三维漂移动画；
- 影响场驱动珊瑚节点生长、分支跟随、健康度和颜色反馈；
- 鼠标移动吸引鱼群，左键投食/拖拽投食，Shift+左键播种，右键修剪，滚轮缩放视角；
- 真实 Three.js 透视水族箱，包含玻璃箱体、后壁、底面、三维深度鱼群和上浮气泡；
- 可调复古后处理：Bayer 抖动、扫描线、RGB 色差、CRT 曲面和滤镜强度；
- 程序化珊瑚骨架，用于验证后续生态层的画面承载。
- Genome presets：四组可切换的坐标、迭代深度、色板和滤镜强度组合，支持实时回退到自定义参数。
- 3D aquarium interior：封闭六面箱体、前后/左右壁、顶部水面、底砂和不同 Z 轴深度的鱼群、珊瑚与气泡。
- 交互反馈层：投食、播种、修剪、预设切换和暂停都有状态提示与低音量事件音效；拖拽投食使用按事件类型的节流，避免连续操作造成声音轰鸣。
- 无障碍与性能提示：画布支持键盘聚焦、Space 暂停和 R 重置，面板控件有可见焦点与跳转链接；运行帧率连续偏低时会显示 GPU 提示。

## 里程碑

- M0 技术验证：Three.js 场景 + 曼德博罗集 Shader + 像素后处理
- M1 生态内核：Boids 鱼群 + 珊瑚生成 + 生态影响场
- M2 闭环串联：鱼群 → 影响场 → 珊瑚生长/色彩反馈
- M3 体验打磨：像素滤镜增强、调色板与 UI、音效
- M4 存档与发布：存档/导出、性能调优、发布
