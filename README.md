# 《像素分形水族箱》Pixel Fractal Aquarium

一个将数学之美与数字生命融合的交互式桌面生态——曼德博罗集作为海底"基因图谱"动态编码珊瑚礁的形态，鱼群的实时游弋轨迹又反过来影响珊瑚的生长与色彩，形成"基因→骨骼→生命→反馈基因"的闭环生态；整个体验用像素风格的复古滤镜包裹。

**技术栈**：TypeScript + Three.js（WebGL2）+ GLSL Shader · **构建**：Vite

## 项目结构

```
7days/
├── 立项文档.md        # 立项文档（含架构、里程碑、验收标准）
├── src/               # 源码（Three.js 场景、分形 Shader、生态模拟）
└── docs/              # 设计文档（规划中）
```

## 快速开始

```bash
npm install
npm run dev
```

（脚手架搭建中，`npm run dev` 暂不可用。）

## 里程碑

- M0 技术验证：Three.js 场景 + 曼德博罗集 Shader + 像素后处理
- M1 生态内核：Boids 鱼群 + 珊瑚生成 + 生态影响场
- M2 闭环串联：鱼群 → 影响场 → 珊瑚生长/色彩反馈
- M3 体验打磨：像素滤镜增强、调色板与 UI、音效
- M4 存档与发布：存档/导出、性能调优、发布

详见 [立项文档.md](./立项文档.md)。
