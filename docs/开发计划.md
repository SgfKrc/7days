# 像素分形水族箱分期开发计划

> 版本：v0.1 · 2026-09-06  
> 计划依据：[立项文档](./立项文档.md)。本文件把里程碑拆成可独立验收的开发票据（Ticket），每张票据尽量控制在 0.5～2 个工作日。

## 交付规则

- 每期结束必须有可启动的 `npm run dev` 和可演示的主流程，不以“代码完成”代替验收。
- 渲染、模拟、界面分别维护边界；跨模块通过明确的数据结构连接，避免把后续 Boids/生态场耦合进 M0 验证代码。
- 所有参数默认值来自立项文档；新增参数要同步写入存档版本和验收记录。
- 性能测试以 Chromium 桌面浏览器为主，至少记录分辨率、设备像素比、实例数量和平均帧率。

## M0 技术验证（第一期）

### M0-01 工程脚手架 `[已完成]`

- 初始化 TypeScript + Vite + Three.js 项目和构建脚本。
- 固定 `strict` 类型检查和 Vitest 单元测试入口；M0 先以 `src/main.ts` 验证完整链路，模拟逻辑已抽到 `src/core`，M1 再按渲染/UI 边界拆分目录。
- 验收：`npm run build` 成功，页面可由 Vite 启动。

### M0-02 曼德博罗基因 Shader `[已完成]`

- Fragment Shader 实现 escape-time 迭代，暴露 `cX`、`cY`、`zoom`、`maxIterations`、`palette` uniform。
- 低频更新 `uTime` 作为微弱呼吸脉冲，避免每帧重算参数纹理的额外开销。
- 验收：拖动四个分形参数时画面实时变化，迭代深度上限 192 且无明显卡顿。

### M0-03 像素输出链路 `[已完成]`

- 使用低分辨率 `WebGLRenderTarget`，纹理采用 `NearestFilter` 放大。
- 后处理 Fragment Shader 加入 4×4 Bayer 有序抖动和 CRT 扫描线开关。
- 验收：切换开关可观察到像素块、色阶和扫描线变化，窗口缩放后链路仍保持正确比例。

### M0-04 参数控制台 `[已完成]`

- 实现曼德博罗坐标、迭代深度、缩放、调色板、滤镜和像素密度控件。
- 提供暂停和重置，所有控件更新画面且不刷新页面。
- 验收：5 分钟连续操作无控制台报错；移动端窄屏面板不遮挡主画面操作区。

### M0 退出条件

- [x] 可运行的 Three.js 场景和分形 Shader。
- [x] Nearest + Bayer 像素化后处理。
- [x] 参数控制台和暂停/重置。
- [ ] 记录至少一台桌面设备的帧率和构建体积（启动后补充到本节）。

## M1 生态内核（第二期）

1. `M1-01` `[已完成]`：定义 `FishState`、`CoralNode`、`InfluenceCell`，实现确定性随机数、坐标环绕和边界测试。
2. `M1-02` `[已完成]`：实现二维空间哈希和 **Boids（鸟群算法）**，支持分离/聚合/对齐邻域查询；模拟逻辑不依赖 Three.js。
3. `M1-03` `[已完成]`：以 genome seed 驱动确定性分支生长，输出带父子关系、深度和健康度的珊瑚骨节节点。
4. `M1-04` `[已完成]`：实现 64×64 三通道影响场，提供养分/扰动/活跃度写入、采样、指数衰减和平均值 API。
5. `M1-05` `[已完成]`：Three.js 3D 动画层，使用 NearestFilter 像素鱼 Sprite，加入四种不同体型、鳍/条纹/眼睛细节、深度分层、游泳摆动和基于速度向量的严格朝向同步。

退出条件：模拟逻辑可脱离渲染单测；典型桌面设备上 3,000 条鱼保持 60 FPS 目标的可行性数据。

### 本期补充验收

- [x] 鱼头朝向与 `velocity` 向量一致，速度接近零时保持上一朝向避免抖动。
- [x] 鱼群至少包含四种可辨识的像素体型，而非单一轮廓换色。
- [x] 像素鱼纹理为 32×20，包含身体高光、眼睛、尾鳍/胸鳍、阴影和物种差异化结构。
- [x] 双帧摆尾动画、转向角度缓动和转向挤压，让朝向变化在低分辨率下可见。
- [x] 鱼群轨迹实时写入影响场，底部活动读数改为影响场平均值。

## M2 闭环串联（第三期）

1. `M2-01` `[已完成]`：鱼群按轨迹写入养分/扰动/活跃度，支持按物种半径、速度和转向强度计算影响增益。
2. `M2-02` `[已完成]`：珊瑚按影响场调节生长速率、分支位置、健康度和色彩亮度；节点反馈会沿父子骨架传递。
3. `M2-03` `[已完成]`：实现鼠标移动吸引、左键投食/拖拽投食、Shift+左键播种、右键修剪和滚轮缩放；增加食物脉冲与反馈高亮层。
4. `M2-04` `[已完成]`：升级为真实 Three.js 3D 水族箱，建立前玻璃、后壁、左右侧壁、顶部水面和底砂组成的内部空间；鱼、珊瑚、气泡均在体积内使用 Z 轴深度，保留透视相机和 Raycaster 交互投射。

退出条件：新用户不阅读文档也能在 5 分钟内观察到“播种 → 鱼群聚集 → 珊瑚变化”。

## M3 体验打磨（第四期）

- `M3-01` `[已完成]`：扫描线、RGB 通道色差、CRT 曲面选项和统一滤镜强度控制，全部接入后处理 Shader 与控制台。
- `M3-02` `[已完成]`：调色板编辑器与基因参数预设。新增四组可切换的坐标、迭代、色板和滤镜强度组合，并保持其他实时滤镜开关不变。
- `M3-03` `[已完成]`：交互音效与事件反馈节流。投食、播种、修剪、预设切换、暂停和重置有统一状态提示；Web Audio 延迟初始化，按事件类型节流，避免拖拽投食造成声音轰鸣。
- `M3-04` `[已完成]`：无障碍检查、窄屏布局、键盘焦点和性能提示。画布支持键盘聚焦与 Space/R 快捷键，控件提供可见焦点、跳转链接和 ARIA 状态；低帧率会显示 GPU 提示。

## M4 存档发布（第五期）

- `M4-01`：设计带 `schemaVersion` 的快照结构，覆盖 genome、珊瑚节点、种群统计、影响场。
- `M4-02`：实现迁移函数、localStorage 保存/读取和 JSON 导入导出。
- `M4-03`：按验收设备做性能、浏览器兼容和内存检查。
- `M4-04`：生成静态产物，补充部署说明和版本变更记录。

## 风险检查点

| 检查点 | 触发条件 | 处理 |
| --- | --- | --- |
| GPU 分形过重 | Shader 迭代或视口放大导致帧率持续低于 50 | 降低纹理更新频率、限制迭代深度、保持低分辨率 RT |
| Boids CPU 瓶颈 | 3,000 个体邻域查询超过帧预算 | 空间哈希；必要时把位置更新迁移到 GPU |
| 反馈不可见 | 影响场变化低于视觉阈值 | 提供反馈增益和对比模式，先保证可观察再调真实感 |
| 滤镜损失可读性 | 控件或交互高亮被量化吞掉 | UI/高亮独立于低分辨率 RT，提供一键关闭 |
